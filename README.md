## Background
Created using the Godot engine, as a personal project for a friend's space-themed DnD campaign, allowing them to easily add / swap the audio files (they intend to produce many relevent audio files themselves, however i have made some fun 'placeholder' audios in the meantime)

# Features / usage
Fully procedural radio-idents, including: Stingers, intros, echo-chatters, talk-show backing tracks, and the talk-shows themselves. With just the default files, there are 396 possible radio idents.

Customizable, quick-swap themes. Swaping to a new theme will result in any future audio tracks being pulled from the respective theme-named folder from the respective area (i.e, music, ads, etc), so the user can fully customise what tracks play and where.

Customize the minimum time between adverts, the minimum time between talk segments, and the names of the soundbanks.

Add / delete music files, advert files, talk-show files, special broadcast files, sound-bank files, and all radio-ident component audio files.

Skip to a new music track / advert / talk-show / special announcement when needed.

Play sounds from the soundbanks, for added ambience / immersion.

Fully quick-saving. Closing and re-opening the app will land you back at the same place within the song, in the same theme, with the same 'time since' and 'min time to' thresholds.

A collection of pre-made 'placeholder tracks' for ads and talk-shows.

Various easter eggs I have hidden around. Can you find all 5?
